像 Typora 一样写 Markdown

左侧选文章。正文在「即时渲染」里直接写，标题、日期、分类和标签在顶部改；需要动 front matter 或 HTML 时切到「源码」。

点「在 Typora 中打开」会用本机 Typora 打开当前文件。Typora 保存后，这里会自动同步，不需要手动刷新。

Ctrl + S 保存，Ctrl + P 筛选文件，Esc 退出专注模式。顶部开启「构建后发布」时，保存并发布会自动推送到 GitHub，不会弹出登录窗口。
